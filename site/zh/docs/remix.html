Remix

内置实时音效

Remix 是 LoFiBox 0.2.0 中以内置插件形式接入的 DSP 功能。 它把创作型声音染色放入实时音频链路，同时所有切换都仍然走 runtime command bus。

切换顺序

runtime 会按 OFF -> Radio -> Tape -> Vinyl -> OFF 循环。 切换是热更新，不需要重启当前曲目。

界面控制方式
GUI按 R。应用内 F1 help 也会列出这个快捷键。
TUI按 R；小写 r 保留给远程连接 reconnect 流程。
WebUI按 R / r，或在 Settings 中点击 CYCLE。
CLI对正在运行的 runtime 执行 lofibox remix。

三种质感

Radio

窄频 AM 电台感：带宽收窄、立体声向单声道靠拢、中频凸起、 接收机噪声、慢速 flutter、随机漂移和饱和的载波质感。

Tape

旧磁带的温暖：低频厚度、高频滚降、wow 与 flutter、 磁带底噪和柔和饱和，让声音更旧、更暖。

Vinyl

黑胶唱机纹理：轻微 wow、唱头染色、表面噪声、灰尘 click、 偶发 scratch decay 和温和饱和。

插件边界

内置插件 id 是 io.github.vicliu624.lofibox.effect.remix。 它注册 remix.radio、remix.tape、remix.vinyl 三个 effect descriptor。 这个设计为之后继续增加内置或外部音效留出扩展点，而不是把 runtime 写成固定 UI 分支。

CLI 示例

lofibox remix
lofibox remix --json
lofibox eq show
lofibox eq show --json
runtime 边界： Remix 是播放时音效命令，不是 metadata 修改，也不是曲目转码。 它只影响当前播放状态，不会写回音乐文件。
